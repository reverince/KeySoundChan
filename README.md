# KeySoundChan

키보드 입력 시 사운드와 이미지를 재생하는 프로그램

## 기능

- 키 누를 때 / 뗄 때 사운드 재생
- 키 입력마다 이미지 전환 (GIF, 다중 이미지)
- 미니 모드 (OBS 캡처용 투명 창)
- 시스템 트레이 최소화

## 빌드

```bash
dotnet build -c Release
```

## 사용법

1. 사운드 파일 선택 또는 프리셋 선택
2. (선택) 이미지/GIF 등록
3. 🔲 버튼으로 미니 모드 전환

### 미니 모드

- 좌클릭 드래그: 창 이동
- 우클릭: 미니 모드 종료
